# portfolio

個人名片頁：聯絡方式與名片資訊的單頁靜態網站。

## 修改內容

打開 `index.html`，找到 `const CARD = { ... }` 這一段，改裡面的值即可。
每個按鈕點一下會複製對應內容；留空字串 `""` 的欄位會顯示「待補」。

## 上線（GitHub Pages）

1. 到倉庫的 **Settings → Pages**
2. **Source** 選 `Deploy from a branch`
3. **Branch** 選 `main`、資料夾選 `/ (root)`，按 Save
4. 約一分鐘後網址為 <https://bbkuan.github.io/portfolio/>

## 本機預覽

直接用瀏覽器打開 `index.html`，不需要任何建置步驟。
